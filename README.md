# Data & Security Copilot

## Overview

Data & Security Copilot is an AI-powered platform for database engineers,
data scientists, and security analysts.

The application combines:

- PostgreSQL
- FastAPI
- React
- Ollama
- Machine Learning
- Fraud Detection
- SQL Playground
- Retrieval-Augmented Generation (RAG)

## Project Goals

- AI-powered SQL assistant
- Banking fraud detection
- Threat monitoring
- Interactive SQL playground
- Database documentation assistant

## Tech Stack

- FastAPI
- PostgreSQL
- React
- Redis
- Celery
- Kafka
- pgvector
- Ollama
- Docker
